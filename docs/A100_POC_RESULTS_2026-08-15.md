# Colab A100 Proof-of-Concept Results

Run date: 15 August 2026 (America/Toronto), 16 August 2026 (UTC)

## Verdict

The Phase 3 true-5% MNIST Mini-VLA feature-proxy run completed on an
NVIDIA A100-SXM4-80GB for seeds 42, 123, and 1024. All uniform and FT-NCFM
min-max runs were finite and passed the predeclared convergence gate. This is
evidence that the current influence-aware distillation plumbing runs
deterministically on the paper-class GPU and scales from 1,000 to 60,000 source
records.

It is not a replication of the paper's VLA performance findings. The proxy has
no robot simulator, outputs joint feature tensors rather than reusable
`(vision, language, action)` records, and has no downstream CALVIN, Meta-World,
or LIBERO success-rate evaluation. In this proxy's CF-loss diagnostic, FT-NCFM's
raw final loss was lower in only one of three true-5% seeds.

## Three-seed true-5% analysis

| Diagnostic | FT-NCFM | Uniform NCFM |
| --- | ---: | ---: |
| Mean final CF loss | 0.03095 | 0.02290 |
| Sample standard deviation | 0.01563 | 0.00529 |
| Convergence passes | 3/3 | 3/3 |
| Lower raw final loss (descriptive only) | 1/3 | 2/3 |

The paired FT-minus-uniform final-loss differences are `+0.02748`, `+0.00103`,
and `-0.00436`; the mean difference is `+0.00805`. These variants optimize
different weighted target distributions, so their raw losses are not an
apples-to-apples performance metric. The result provides no evidence of an FT
advantage, but it also cannot establish that uniform NCFM performs better. Three
proxy seeds do not justify a significance claim, and CF loss is not a
robot-policy success metric.

## Comparison boundary

| Dimension | FT-NCFM paper | This completed run |
| --- | --- | --- |
| Data | CALVIN, Meta-World, LIBERO trajectories | MNIST-derived pseudo-VLA records |
| Model | ViT-B/16 plus six-layer Transformer policy | Small convolutional guide and feature proxy |
| Contrastive verification | Simulator-grounded minimal counterexamples | Deterministic visual-only proxy perturbations |
| Synthetic record | VLA coreset | Joint feature tensor |
| Primary metric | Robot success rate / average sequence length | Characteristic-function training loss |
| Scale conclusion | 5% coreset performance and GPU-hour claims | Numerical stability and runtime only |

Therefore the paper's reported 85--90% full-data performance recovery and
greater-than-80% training-time reduction remain untested here.

## Issues found and fixed during the run

1. PyTorch's deterministic CUDA mode rejected adaptive average-pooling backward
   on the A100. The fixed 7x7-to-2x2 proxy path now uses the mathematically
   equivalent deterministic `AvgPool2d(kernel_size=4, stride=3)`, with equivalence
   and output-shape tests (`0161170`). The initial failure log remains in the
   artifact archive.
2. A resumed invocation initially replaced the aggregate summary with only its
   requested seeds. Aggregation now discovers every complete persisted seed and
   orders them numerically, with a regression test (`3aa1328`). The final
   aggregate contains 42, 123, and 1024.
3. Google Drive credential propagation failed in the Colab VM. The run used
   `/content/ft-ncfm-results`; the final ZIP was transferred locally and verified
   byte-for-byte by size and SHA-256 before the runtime was deleted.
4. The final audit found that resume detection checked filenames rather than
   file integrity and aggregation did not reject incompatible complete seeds.
   The runner now writes SHA-256 checksums, validates JSON/JSONL/PT contents and
   finite tensors, checks seed identity, and rejects mismatched configs, commits,
   providers, overrides, devices, or undeclared seeds before aggregation.

## Next research gate

Phase 3 still needs the planned full-data, random-5%, and influence-only
downstream proxy baselines if a complete proxy ablation matrix is desired. The
next paper-relevant gate is a single LIBERO task on Linux/CUDA with:

1. genuine `(vision, language, action)` records and a clean evaluation split;
2. simulator-backed object substitution, scale, and position counterexamples;
3. the paper-style ViT-B/16 plus six-layer Transformer policy, or a clearly
   separated smaller surrogate;
4. full data, random 5%, influence-only 5%, uniform NCFM 5%, and FT-NCFM 5%;
5. seeds 42, 123, and 1024, reporting downstream success, wall time, GPU-hours,
   peak memory, and raw per-seed artifacts.

Before that run, preregister a factorial ablation for influence sign, ranking
direction, and normalization, and separate the influence-reference validation
partition from the untouched final evaluation partition.
