# Independent Audit — 15 August 2026

The audit was performed by an independent, read-only agent against clean commit
`0b61848`. No files were changed by the auditor.

## Verdict

- No P0 issue was found.
- Go for an inexpensive AWS GPU infrastructure smoke test with automatic shutdown.
- No-go for paper-comparable FT-NCFM or LIBERO claims until the P1 research gaps
  below are resolved.

## P1 findings

1. **Influence sign and ranking remain ambiguous.** The implementation applies the
   paper's leading minus sign and selects the largest scores. Under classical
   influence semantics, that may prioritize harmful samples. Both sign and ranking
   directions require a declared ablation.
2. **The completed run was 5% of 5%.** It selected 3,000 MNIST records and then
   generated 150 synthetic records: 0.25% of the full corpus. It must not be called
   a paper-comparable 5% coreset.
3. **There is no isolated downstream test split.** The official MNIST test split is
   currently the influence reference set and cannot later double as an untouched
   evaluation split.
4. **The synthetic output is a joint feature proxy, not reusable `(V, L, A)` data.**
5. **Counterexamples are image perturbation proxies, not semantic,
   simulator-grounded interventions.**
6. **Only uniform and weighted NCFM were executed.** The six predeclared baselines
   and downstream task-success evaluation remain outstanding.

## P2 findings

- The weighted sampler is not integrated into the end-to-end experiment.
- Reference gradients are averaged over validation data rather than tied to a
  task-relevant test case; this is a declared but unvalidated choice.
- CUDA determinism and GPU/cloud provenance were not recorded at the audited commit.
- Tests cover components but not sign/ranking, split isolation, trainable coreset
  output, downstream improvement, CUDA resume, or the full scientific pipeline.

## Actions taken after the audit

- Preserved the completed result as a clearly named nested-fraction smoke test.
- Added a true 5%-of-full-corpus configuration.
- Added deterministic CUDA controls and GPU, driver, CUDA, cuDNN, AWS, container,
  and peak-memory provenance to run manifests.
- Added cost-gated AWS infrastructure with no inbound ports, SSM access, encrypted
  storage, S3 artifact retention, and two independent automatic-stop mechanisms.

The remaining P1 scientific gaps are intentionally not hidden by the AWS setup.
