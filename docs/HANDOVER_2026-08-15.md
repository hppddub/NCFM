## Completed sign/ranking/normalization ablation

The isolated one-seed factorial gate ran at `d9ad359` with 3,000 source
samples, 512 influence-reference samples, 1,024 selection-validation samples,
2,048 untouched final-test samples, and a 150-record synthetic coreset. It
evaluated two sign conventions, two ranking directions, and three
normalizations. Selection used only the selection-validation partition.

Selected condition:

`sign=paper__rank=smallest__norm=positive_shift`

| Variant | Selection MSE | Untouched test MSE |
| --- | ---: | ---: |
| Full data | 0.00071194 | 0.00075073 |
| Random 5% | 0.00074788 | 0.00079503 |
| Uniform NCFM | 0.00714791 | 0.00723730 |
| Influence-only 5% | 0.06235285 | 0.06278767 |
| Selected FT-NCFM | 0.00631360 | 0.00599230 |

The selected FT condition improved test MSE by about 17.2% relative to uniform
NCFM, but it remained about 7.5 times worse than random 5%. This is a
single-seed MNIST-derived feature proxy, so it is a configuration-selection
gate, not evidence that FT-NCFM improves a robot policy.

## Scientific interpretation limits

- The factorial selection used one proxy seed; it was not a multi-seed model
  selection study.
- The implemented LIBERO policy is a compact surrogate, not the paper's full
  ViT-B/16 plus six-layer Transformer.
- The synthetic coreset contains learned latent/action tensors rather than
  reusable raw vision-language-action trajectories.
- Current contrastive perturbations are deterministic tensor transforms; they
  are not yet simulator-grounded object substitutions.
- One task, one seed, and five rollouts can validate the pipeline, but cannot
  reproduce the paper's benchmark-wide success-rate claims.
